# 🤖 GenAI-Powered Resume/Interview Coach

> A comprehensive AI-powered tool that helps job seekers optimize their resumes and ace interviews using OpenAI, LangChain, and RAG (Retrieval Augmented Generation).

## 🎯 Project Overview

This project combines modern GenAI technologies with full-stack development to create a practical career preparation tool. Perfect for demonstrating both AI integration skills and software engineering capabilities.

### Key Features

- **Resume Analysis & Optimization** - AI-powered suggestions for better keywords and phrasing
- **Personalized Interview Questions** - Generated based on your resume and target job description
- **STAR Method Feedback** - Structured scoring and improvement suggestions for interview answers
- **RAG-Powered Knowledge Base** - Stores and retrieves relevant interview best practices

### Tech Stack

- **Frontend**: React + Tailwind CSS
- **Backend**: Node.js/Express or Python/FastAPI
- **AI**: OpenAI GPT-4/3.5, LangChain
- **Vector DB**: Pinecone or FAISS
- **Deployment**: Vercel/Netlify + Render/AWS
